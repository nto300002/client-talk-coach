# 受託開発向けAI顧客折衝トレーニングアプリ

## 画面デザイン

# テーマ

本MVPの画面テーマは、全体的に薄いオレンジ色を基調とする。

緊張しやすいユーザーが使う練習アプリであるため、強い赤、暗い警告色、過度なコントラスト、採点アプリらしい圧迫感を避ける。薄いオレンジを、あたたかさ、再挑戦しやすさ、落ち着いた業務練習感を支える色として使う。

## カラーパレット

| 用途 | 色 | 目的 |
|---|---|---|
| Page background | `#fff7ed` | 薄いオレンジの背景 |
| Surface | `#fffbf5` | 入力面・設定面の背景 |
| Primary | `#ea7a1a` | 主ボタン、選択状態 |
| Primary soft | `#fed7aa` | 選択チップ、弱い強調 |
| Border | `#fdba74` | 区切り線、入力枠 |

| Text muted | `#6b7280` | 補足 |
| Success | `#15803d` | 良かった点 |
| Warning | `#b45309` | 注意、保存上限 |
| Error | `#b91c1c` | 復旧不能エラーのみ |

## デザイン原則

- 1画面につき主目的を一つにする。
- 主ボタンは原則一つにする。
- 主ボタンはオレンジ、補助ボタンは白背景または薄いオレンジ背景にする。
- 警告は赤を多用せず、原則として薄いオレンジまたはアンバー系で表示する。
- 失敗、不合格、低評価のような表現を避ける。
- 練習中は採点情報を出さず、録画状態、AI発話状態、経過時間、一時停止だけを見せる。
- 角丸は8px以下を基本にする。
- カードの入れ子を避ける。
- 文字は小さくしすぎず、操作ボタンは緊張時でも押しやすい大きさにする。
- アイコンが使える操作には、テキストだけでなくアイコンも併用する。

## 画面状態の色ルール

| 状態 | 表現 |
|---|---|
| 通常 | 薄いオレンジ背景、濃いグレー本文 |
| 選択中 | オレンジ枠、薄いオレンジ塗り |
| 実行可能 | オレンジ主ボタン |
| 無効 | グレー文字、低彩度背景 |
| 注意 | アンバー背景、短い説明 |
| 危険操作 | 白背景に赤系文字、確認ダイアログ必須 |
| 成功 | 緑テキストを少量、背景は薄いまま |

# 1. 設計方針

本MVPでは、緊張しやすいユーザーが迷わず操作できることを優先する。

* 1画面につき主目的を一つにする
* 主ボタンは原則一つにする
* 練習中は詳細な採点を表示しない
* 「失敗」「不合格」などの表現を使わない
* AI評価より先に自己評価を入力する
* 改善点は一つだけ表示する
* 緊急終了後も自己評価と振り返りへ進める
* 録画動画が削除されても分析結果は保持する
* 保存録画は最大20本とする

# 2. API表記

画面詳細では、処理先を次のように表記する。

| 表記               | 意味                                        |
| ---------------- | ----------------------------------------- |
| HTTP API         | Next.js Route Handlerを通じて外部サービスを利用        |
| Use Case         | Application層のユースケース                       |
| Local Repository | IndexedDB／Dexieへの保存・取得                    |
| Browser API      | MediaRecorder、Web Audio、SpeechSynthesisなど |

HTTP APIは次の4種類だけとする。

```text
POST /api/v1/stt/transcriptions
POST /api/v1/ai/client-responses
POST /api/v1/ai/conversation-analyses
POST /api/v1/admin/evaluation-comparisons
```

シナリオ選択、履歴保存、動画保存、自己評価などのローカルデータ処理はHTTP API化しない。

# 8. 共通ダイアログ

## 練習終了確認

```text
会話を終了しますか？

保存済みの録画と会話内容は保持されます。

[続ける] [終了する]
```

## 緊急終了

```text
練習を安全に終了します。

この操作は失敗として記録されません。
保存できた内容を使って振り返りを行えます。

[戻る] [安全に終了]
```

## 動画自動削除予定

```text
録画の保存上限は20本です。

新しい録画を保存すると、最も古い
非お気に入り動画が自動削除されます。
分析結果と履歴は残ります。

[キャンセル] [練習を開始]
```

## 全録画がお気に入り

```text
20本すべての録画がお気に入りです。

新しい録画を開始するには、
お気に入りを解除するか動画を削除してください。

[録画管理へ]
```

# 9. 画面共通エラー表示

| エラー   | 表示                  |
| ----- | ------------------- |
| カメラ拒否 | カメラの利用が許可されていません    |
| マイク拒否 | マイクの利用が許可されていません    |
| STT失敗 | 音声を文字に変換できませんでした    |
| AI失敗  | 顧客の返答を作成できませんでした    |
| TTS失敗 | 音声を再生できません。文章で表示します |
| 録画失敗  | 録画を開始できませんでした       |
| 保存失敗  | 端末への保存に失敗しました       |
| 容量不足  | 録画を保存する空き容量がありません   |
| 分析失敗  | 一部の分析を完了できませんでした    |
| 不明エラー | 処理を完了できませんでした       |

エラー表示には、会話本文、動画、自己評価、外部APIの生エラー、スタックトレースを含めない。

# 11. 画面設計の受け入れ条件

* ホームから結果画面までの主要フローが成立する
* ブラウザの戻る操作で不正な状態へ遷移しない
* 自己評価前にAI評価を表示しない
* 練習中に詳細評価を表示しない
* 緊急終了後も自己評価画面へ進める
* HTTP APIを使わずにシナリオ選択・履歴表示が動作する
* API失敗時に保存済み録画を失わない
* 動画削除後も分析結果を閲覧できる
* 21本目保存時に最古の非お気に入り動画だけを削除する
* 20本すべてがお気に入りなら録画開始をブロックする
* 改善点は一画面に一つだけ表示する
* 一般ユーザー向け画面から管理者機能へ誤遷移しない
