# Issue 047: 練習時間カウントダウンと時間切れ終了

## 目的

設定した5分、7分、10分の練習時間を会話画面で可視化し、期限到達時に安全かつ一度だけ練習を終了する。

## 振る舞い

- 練習中に残り時間と経過時間を分:秒形式で表示する。
- 練習時間は練習設定で選択した5分、7分、10分を使用する。
- 残り1分になった時点で、一度だけ会話をまとめる通知を表示する。
- 一時停止中はカウントダウンを進めず、再開後に残り時間から再開する。
- 残り時間が0になった場合、録画・会話を保存して`time_expired`で自己評価画面へ遷移する。
- 終了要求が重複しても、録画停止・保存・遷移は一度だけ実行する。
- 自己評価画面では、時間切れを通常終了とは別に`時間終了`と表示する。

## 受け入れ要件

- [x] 残り時間と経過時間を会話画面に表示する。
- [x] 選択した時間からカウントダウンする。
- [x] 残り1分の通知を一度だけ表示する。
- [x] 一時停止中にカウントダウンが進まない。
- [x] 時間切れで`time_expired`を保存し、自己評価画面へ一度だけ遷移する。
- [x] 自己評価画面に`終了理由: 時間終了`を表示する。

## TDDテスト要件

### Unit Test

- 5分、7分、10分の経過時間と残り時間を計算する。
- 残り1分の通知を一度だけ返す。
- 期限切れイベントを一度だけ返す。
- 一時停止中は経過時間を増やさず、再開後に進める。

### E2E Test

- ローカル環境を起動して5分の練習を開始する。
- ブラウザ時計を4分進め、残り1分通知を確認する。
- さらに1分進め、自己評価画面への遷移と`time_expired`の保存を確認する。
