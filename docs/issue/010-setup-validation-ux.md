# 010 - 練習設定の早すぎるバリデーション表示を修正

## 振る舞い

練習設定は依存する項目を段階的に表示する。設定全体の妥当性は常に計算し、未完了時は開始ボタンを無効にする。一方、未操作の後続項目にはエラーメッセージを表示しない。

各フィールドのエラーは、そのフィールドを操作して無効な値になった場合だけ表示する。シナリオ変更で後続項目が未選択へ戻った場合も、単に未完了として扱い、赤いエラー表示はしない。

## 受け入れ要件

- シナリオだけを選択しても、具体的場面・難易度・顧客タイプ・重点項目・自己評価のエラーは表示されない。
- 未完了の間は開始ボタンが無効のままである。
- 緊張度または自信度に範囲外の値を入力すると、その入力欄だけにエラーが表示される。
- 正しい設定をすべて入力すると、開始ボタンが有効になる。

## TDDテスト要件

- Component Test: シナリオ選択直後に未操作項目のエラーが表示されない。
- Component Test: 範囲外の自己評価だけがエラーを表示する。
- Component Test: 完全な設定で開始処理が呼ばれる。
- E2E Test: ローカル環境で段階的に設定し、不要なエラーが画面に出ないことを確認する。
